ERUVAKA V&V DASHBOARD — PHASE 1 FINAL

Main Overview:
The Overview is an overall V&V dashboard, not a project-only dashboard.

It shows the same validation metrics for every area:
1. Projects
2. Sourcing
3. Field Issues
4. Quality
5. R&D

Each area is displayed as a separate table on the main page with:
- Item
- Total Test Cases
- Executed
- Pass
- Fail
- Pass %
- Progress
- Status

Each item is treated as a validation item because every area will eventually contain test cases.

Clicking an item opens its detailed validation view with:
- KPIs
- Execution progress
- Pass rate
- Category performance
- Failure analysis
- Test cases
- Search/filter

Sidebar intentionally does not list project/item names to avoid clutter as the portfolio grows.

Dummy items:
Projects: Moving Feeder, PM 250 Max, Pond Mother
Sourcing: Solar Panel, LED Display
Field Issues: Aero Wing Disk
Quality: PM250 Conduit Cable
R&D: Lump Cutter

Open index.html in Chrome or Edge.
